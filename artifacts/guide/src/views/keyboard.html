Keyboard & Navigation Model (lazygit)

Yes, gitten is built on lazygit's exact keyboard model. As stated in AGENTS.md: "A desktop git client with lazygit's keyboard model. Rust, GPUI." and in core/src/command.rs: "The shipped keyboard. lazygit's, where lazygit has an opinion, and vi's where it does not."

lazygit Numbering vs. The Visual Mockup

In the visual design mockup (Image #1), the designer numbered the three visible columns directly (1 Files, 2 Branches, 3 Stash, 4 Commits, 5 Diff).

In canonical lazygit (and in core/src/command.rs), the numbering reads down the working tree stack:

  • 1 Status: Working directory state, upstream drift, ahead/behind sync (↑2 ↓0).
  • 2 Files: Staged, unstaged, untracked, and conflicted files.
  • 3 Branches: Local branches, remotes, and tags.
  • 4 Commits: The commit log, branch lanes, and history graph.
  • 5 Stash: The stash stack.
  • 0 or ↵ (Enter) / Tab: Diff (Main View): Enters the diff pane to scroll hunks or stage lines.
  • Esc: Exits the diff view back to the side panels.

You can toggle between Canonical Lazygit (1..5 + 0/↵) and Mockup (1..5) in the toolbar dropdown above. Both schemes dispatch through core::command.

1. Panel Navigation (Vim + Arrows)

Shortcut Action lazygit & core Mapping
1 .. 5 Direct jump to panel status.focus, files.focus, branches.focus, commits.focus, stashes.focus
0 or ↵ Focus main diff panel diff.focus (enters diff from any list)
Esc Return to sidebar / cancel Exits diff focus back to list; closes modals or menus
h / l or ← / → Walk pane left / right pane.left, pane.right
j / k or ↓ / ↑ Move selection down / up cursor.down, cursor.up
[ / ] Previous / next file in diff diff.prev-file, diff.next-file
< / > (or H / L) Scroll diff horizontally view.left, view.right
Ctrl+u / Ctrl+d Page up / page down Half-page scroll in active list or diff

2. Global Git Verbs

Shortcut Command Description
P (Shift+p) repo.push Pushes local branch to upstream remote (git push)
p repo.pull Pulls upstream changes onto checked-out branch (git pull)
f repo.fetch Fetches latest refs from remotes without merging
R (Shift+r) repo.refresh Re-runs reads across all panes; refreshes git state
y copy.selection Copies selected commit SHA, branch name, or file path to clipboard
/ *.search Opens interactive live filter in the focused list
? help.show Opens comprehensive lazygit keymap cheat sheet overlay

3. Contextual Pane Verbs

Pane Shortcut Action Behavior
Files (2) ␣ (Space) Stage / unstage file Toggles selected row between Staged and Unstaged
c Commit staged Opens commit message editor for staged changes
A Amend commit Amends staged changes into HEAD commit
a Stage all Stages (or unstages) all files in the working tree
D Discard changes Discards working tree modifications (destructive; asks twice)
s Stash working tree Parks unstaged/working-tree changes into stash
Branches (3) ␣ (Space) Checkout branch Switches HEAD to the selected branch
n New branch Prompts for a new branch name branched from HEAD
r Rebase onto branch Rebases current branch onto selected branch (asks twice)
R Rename branch Renames selected branch
d Delete branch Deletes local branch (destructive; asks twice)
Commits (4) ␣ (Space) Checkout commit Detached checkout onto selected commit
s Squash commit Squashes commit down into parent (rewrites history)
f Fixup commit Melds commit into parent, discarding commit message
d Drop commit Deletes commit from branch history (asks twice)
r Reword commit Edits commit message of selected commit
g Reset menu Opens reset menu: s soft, m mixed, h hard
t Revert commit Creates a new commit reversing the changes of this commit
Diff (0/↵) ␣ (Space) Stage hunk / line Stages the selected diff hunk or line into the index
u Unstage hunk Removes hunk from the index back to working tree
D Discard hunk Discards hunk changes from working tree (asks twice)
e Explain hunk (AI) Toggles contextual AI explanation for currently focused hunk
