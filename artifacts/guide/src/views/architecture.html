GPUI & Core Architecture Seams

How this design guide maps directly to Rust crates in the gitten codebase. As enforced by AGENTS.md: "A client is drawing and input, and nothing else. Everything before it is shared in core."

1. The Four-Crate Pipeline

1. gitten-git

Acquisition layer. The ONLY crate that talks to repository files or spawns the git binary.

2. gitten-core

Pure algorithms. Zero UI dependencies. Differs (Histogram), lane assignment, intraline aligner, themes.

3. gitten-app

Configuration parser, gitten.toml loader, CLI arguments, verb dispatch, and extension runner.

4. shell (GPUI)

Rendering and input only! uniform_list virtualization, canvas Bézier painter, and window chrome.

2. Key Source Code File Mapping

Visual Component Source Location Responsibility
Theme & Colors core/src/theme.rs Theme::dark(), DiffPalette, ChromePalette, contrast ratio math.
Graph Algorithm core/src/graph.rs assign_lanes, MAX_LANES = 12 cap, plan curve halves calculation.
Graph Canvas Rendering shell/src/graph.rs GPUI canvas(), PathBuilder Bézier arcs, ROW_H = 22.0.
Diff Calculation core/src/differ.rs, core/src/align.rs Histogram differ, hunk assembly, word-level intraline pairing.
Diff View Rendering shell/src/views/diff.rs Unified diff rendering, line numbers gutter, intraline token spans.
Window Chrome shell/src/chrome.rs macOS titlebar inset, traffic light handling, window resize.
Command Dispatch core/src/command.rs, shell/src/dispatch.rs Maps keystrokes to command names; executes actions via Repo trait.
