# Feature map

Generated by `./dev features` from `Commands::builtin()` and `Keymap::builtin()` in `core/src/command.rs`. Do not edit it by hand; `./check.sh` fails when it is stale.

Every command, the keys the shipped keymap binds to it (`mode: chord`), whether it writes to the repository, and the first file in each client that spells its name; grep it for the quoted name to land on the line. `—` means the name is not written as a literal there: either the client does not answer it, or it reaches it through a prefix match or a built name. Read the line before trusting the dash. The desktop answers only arrows, Tab, Enter, Esc and `cmd-` chords from the keyboard, so for `gui` the keys column is what the terminal does.
